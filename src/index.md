# Interactive Data Stories

This collection explores how interactive visualizations can turn unfamiliar datasets into clear analytical arguments. It was developed in CUNY Graduate Center's Interactive Data Visualization course using Observable Framework and Observable Plot.

The course supplied the scenarios and datasets unless a project states otherwise. The analysis, visual encodings, interactions, and written conclusions are my work.

## Featured analyses

### Mayoral Mystery

Geospatial campaign analysis combining election results, survey responses, events, and NYC district geometry.

[Open the dashboard](./lab_3/)

### Clearwater Crisis

An investigative environmental data story connecting fish health, water quality, monitoring locations, and surrounding activity.

[Open the dashboard](./lab_4/)

### Subway Staffing

An operations dashboard using ridership, events, incidents, and staffing data to prioritize stations for additional support.

[Open the dashboard](./lab_2/)

### Prolific Pollinators

An exploratory analysis of pollinator morphology, environmental conditions, visit patterns, and nectar production.

[Open the dashboard](./lab_1/)

## Methods and tools

Observable Framework, Observable Plot, JavaScript, CSS, CSV, GeoJSON, TopoJSON, exploratory analysis, geospatial visualization, annotations, interaction design, and narrative explanation.

Project documentation and local setup instructions are available in the [GitHub repository](https://github.com/jborri/Interactive-Data-Vis-Fall2025).
